NEWS_STOCK v4.7.22 — 持股情報總覽整合版

主要內容
1. 持股頁新增「我的持股情報中心」：把收盤行情／未實現損益與近 7 日新聞放在同一區。
2. 每檔持股顯示：近 7 日新聞量、公司事件、核心事件、重大事件、最新重點事件。
3. 近 24 小時有公司事件或重大事件時顯示「有新事件」。
4. 可依「最新事件／新聞活躍度／未實現損益」切換排序。
5. 新聞收藏中尚未持有的股票，顯示在「⭐ 觀察中（收藏但未持有）」區塊。
6. 「查看新聞情報」可直接開啟該股票的個股情報總覽。
7. 不更動持股、成本、交易紀錄、股利、公司行動；本版只整合顯示與新聞資料。
8. PWA / JS / CSS 版本統一到 4.7.22。
