# v4.1 Google Sheet + Apps Script 同步設定

1. 新增一份 Google Sheet，例如「安心股票簿研究同步」。
2. 在 Sheet 選「擴充功能 → Apps Script」。
3. 將本資料夾的 `Code.gs` 全部貼入，取代原本內容。
4. 修改第一段：
   `const SYNC_TOKEN = 'CHANGE_ME_TO_A_LONG_RANDOM_KEY';`
   改成你自己的長密碼，例如 30～60 字元；不要公開到 GitHub。
5. Apps Script 右上角「部署 → 新增部署作業 → 網頁應用程式」。
6. 執行身分選「我」，存取權選可讓你各裝置開啟此 Web App 的選項（個人帳號通常為「任何知道連結的人」）。
7. 完成部署後複製 `/exec` 結尾的 Web App URL。
8. 回到股票簿 → 新聞情報中心 → 我的追蹤 → 跨裝置同步。
9. 貼上 Web App URL、輸入同一組同步金鑰，設定一個同步命名空間，例如 `my-stock-research`。
10. 第一次建議在「資料最完整的裝置」先按「上傳本機」；其他裝置再按「下載並合併」或「智慧同步」。

## 同步範圍
同步的是研究追蹤資料：追蹤主題、已讀狀態、待辦、研究狀態、研究筆記、驗證結果、結案、研究回顧等。股票交易簿本身仍沿用原系統的本機資料機制。

## 衝突處理
智慧同步會先下載雲端資料，再依每個追蹤主題的更新時間合併，最後把合併結果回寫。舊資料不會因為單純下載而整份被直接覆蓋。

## 安全提醒
- `SYNC_TOKEN` 不要放進公開 GitHub 儲存庫。
- Apps Script URL 與同步金鑰建議只在自己的裝置使用。
- Google Sheet 中的 `ResearchSync` 工作表是同步資料儲存區，不建議手動修改其中 payload 欄位。
