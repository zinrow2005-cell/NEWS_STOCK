# NEWS_STOCK 程式結構與維護說明（V4.7.29）

## 1. 整理方式

- 舊版 `index.html` 及 `404.html` 皆包含**完全相同**的約 2 MB JS 與 CSS，修改時可能只改其中一份，產生內容不一致的風險。
- 現在將 JavaScript 移到 `assets/app.js`，將主要 CSS 移到 `assets/app-core.css`，覆蓋樣式移到 `assets/app-overrides.css`，兩個 HTML 頁面共用。
- `app-core.css` 必須先於 `news-center.css`、`portfolio-intelligence.css`；`app-overrides.css` 必須位在這兩者之後，**以確保 CSS 覆蓋順序與舊版一致**。
- 載入順序：獨立開關 `window.__STOCK_LEDGER_STANDALONE__` → `assets/app.js` → `news-center.js` → `portfolio-intelligence.js`。
- 使用現有已建置 bundle，**沒有重新演算或修改 V4.7.28 已修復的現金股利、配股、持股成本邏輯**。

## 2. 修改時應編輯哪個檔案

| 項目 | 檔案 |
|---|---|
| 持股／總覽畫面細節樣式 | `assets/app-overrides.css` |
| 主系統基礎樣式 | `assets/app-core.css` |
| 主系統計算與 React 應用 | `assets/app.js`（**壓縮 bundle，不是 React 原始碼**）|
| 新聞情報中心功能與畫面 | `news-center.js`, `news-center.css` |
| 持股情報中心 | `portfolio-intelligence.js`, `portfolio-intelligence.css` |
| 更新新聞和官方收盤資料 | `scripts/update_*.py` 與 `.github/workflows/` |
| App 快取版本與離線策略 | `service-worker.js` |
| 本版完整記錄 | `CHANGELOG.md` |

## 3. 資料相容與安全事項

1. 使用者交易、股利、券商資料仍保存在**同一網址同一瀏覽器 localStorage**；這個 ZIP **不含**你的個人資料。
2. 升級前應由舊版系統匯出完整 JSON；不要清除瀏覽器資料或直接改 localStorage key。
3. 如果改了程式或 CSS，Service Worker 的 `CACHE_VERSION` 應同步更新以避免舊頁一直快取。
4. `stock-news.json` 與 `market-close.json` 由 GitHub Actions 在執行時更新。新版檔案可能只含初始化或舊資料；新鮮度須上線後確認。
5. 保留 `.github/workflows`；移除 Actions 會停止自動行情及新聞更新。
6. 若改動持股計算，執行 `node tests/test_breakeven.cjs`，並比對實際券商資料。

## 4. 打包方法

在專案根目錄執行：

```bash
python scripts/check_release.py
python scripts/build_release.py
```

輸出 `NEWS_STOCK-v4.7.29-COMPLETE-GITHUB.zip`（預設在專案的上一層），內含全部網站檔案；不把暫存、測試截圖或私人匯出備份放進 ZIP。
