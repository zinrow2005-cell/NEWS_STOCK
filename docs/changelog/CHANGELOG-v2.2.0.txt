安心股票簿 v2.2.0 — 事件類型歷史效果統計

新增：
- 個股情報總覽加入「事件類型歷史效果」面板。
- 依新聞事件分類彙整歷史股價反應。
- 統計 +1 / +3 / +5 / +20 交易日平均報酬。
- 同時顯示中位數、正報酬比例與有效樣本數 n。
- 樣本數分級提示：樣本不足 / 樣本偏少 / 樣本較完整。
- 優先使用目前 stock-news.json 與 market-history.json 中已累積的完整可用歷史，而非只用當前畫面的 7/30/90 天篩選期間。
- 明確標示統計僅為歷史共現，不代表新聞事件造成股價漲跌。

資料邏輯：
- 仍沿用 v2.1：事件前一交易日收盤為基準。
- 休市日新聞順延至下一個可交易日。
- +1/+3/+5/+20 全部以交易日計算。
- 一個事件若屬於多個分類，會各自進入對應分類統計。
