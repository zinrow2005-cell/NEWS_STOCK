安心股票簿 v2.1.0 — 新聞事件 × 股價反應

1. 新增 market-history.json，保存最近約 180 個交易日官方收盤價。
2. GitHub Actions 的市場收盤價更新流程同時更新 market-close.json 與 market-history.json。
3. 新聞事件以事件前一交易日收盤為基準，顯示事件日、+1、+3、+5、+20 交易日價格變化。
4. 休市日新聞自動對齊下一交易日，不以自然日錯算。
5. 個股情報總覽新增事件價格反應比較表。
6. 個股新聞卡新增價格反應區塊。
7. PWA Service Worker 更新至 v21，market-history.json 使用 no-store 讀取最新資料。

注意：市場價格變化受到多項因素共同影響，本功能只做事件前後價格描述，不做因果推論與買賣建議。
