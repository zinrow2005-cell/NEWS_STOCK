NEWS_STOCK v4.7.17 — 橫向閱讀模式＋事件合併健康度校準

主要調整
1. 新聞閱讀模式改為橫向單列，桌機/iPad 不再直式占滿高度。
2. 空間不足時可左右滑動，不強迫換行；手機同樣採橫向滑動。
3. 閱讀模式說明文字改為隱藏，不再常駐佔空間。
4. 事件合併健康度改為更精簡版，保留原始篇數、事件數、壓縮率、多篇事件、最大群組。
5. 健康度新增「留意」區間：壓縮率 >45% 或最大群組 >=7；>55% 或最大群組 >=9 才判偏高。
6. 目前 2317 實測 29篇→20事件、31%壓縮、最大群組4，屬健康區，因此本版不修改事件合併演算法，避免過度校正。
7. PWA cache 更新為 news-v47.17。
