NEWS_STOCK v4.7.16 — 事件合併實測校準版

覆蓋檔案：
- news-center.js
- news-center.css
- service-worker.js

本版重點：
1. 二次智慧合併時間窗依事件性質縮短：市場題材 12h、股價行情 18h、公司事件 30h、其他 24h。
2. 提高標題相似度門檻，低相似度只有在共享明確事件錨點時才允許合併。
3. 移除「投資／合作／取得」這類過寬泛詞作為低門檻合併依據，降低不同公告被誤合併的風險。
4. 個股近 7 日總覽新增「事件合併健康度」：原始篇數、事件數、壓縮率、多篇事件數、最大群組。
5. 壓縮率 >55%（至少20篇）會提示抽查過度合併；<8% 則提示可能仍有重複未合併。

本版不修改 stock-news.json、GitHub Actions 或後端新聞分類。
